# GeekOzon ERP 用户使用手册

面向 Ozon 电商平台的全链路 ERP 管理系统，集成商品采集、AI 智能撰写、自动刊登、选品分析等核心能力，配套 Chrome 浏览器扩展，实现从「货源采集」到「商品上线」的一站式运营。

## 一、系统简介

| 组成 | 说明 |
|------|------|
| **前端** | 浏览器网页版 ERP 管理后台（`http://localhost:5000`） |
| **后端** | Python Flask 服务，同时托管前端页面与 API |
| **扩展** | Chrome 浏览器插件（Manifest V3），在电商商品页一键采集 |

**支持的采集平台（货源）**：Ozon、1688、淘宝、天猫、京东、拼多多、速卖通、亚马逊（美/德/英/法/意/西/加/日/阿联酋）、Wildberries。

**支持的刊登平台（销售）**：Ozon（俄罗斯 / 哈萨克斯坦 / 白俄罗斯）。

## 二、快速开始

### 2.1 启动后端服务

```bash
cd backend
pip install flask flask-cors
python app.py
```

启动成功后访问 `http://localhost:5000` 即可打开 ERP 管理后台。

> **首次使用提示**：如后端提示 `SECRET_KEY` 未配置，属正常开发态提示；正式使用请编辑 `backend/.env` 设置固定密钥（详见部署文档）。

### 2.2 加载浏览器扩展

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 打开右上角「**开发者模式**」开关
3. 点击「**加载已解压的扩展程序**」
4. 选择本项目 `extension/` 目录
5. 加载成功后，浏览器工具栏会出现 GeekOzon 图标

> 扩展默认连接 `http://localhost:5000` 的后端，请确保后端服务已启动。

## 三、核心业务流程

系统围绕一条主线展开，四步走：

```
① 商品采集 ──▶ ② 信息校验 ──▶ ③ 提交 Ozon ──▶ ④ 在线商品
   (扩展/手动)   (类目·属性·SKU·定价)  (发布任务追踪)   (价格·库存·状态同步)
```

| 步骤 | 页面 | 做什么 |
|------|------|--------|
| ① 商品采集 | 采集箱 `/collect` | 用扩展在货源站采集，或手动粘贴 URL；商品进入采集箱 |
| ② 信息校验 | 采集箱 `/collect` | 补全类目、属性、SKU、标题、图片、定价 |
| ③ 提交 Ozon | 上架记录 `/publish` | 提交发布任务，追踪 API 结果与异常 |
| ④ 在线商品 | 在线商品 `/online-products` | 管理已上线商品的价格、库存与状态同步 |

## 五、功能模块详解

### 5.1 首页工作台（`/home`）

运营数据总览页，进入系统的默认页面。

- **运营指标卡片**：今日采集、待上架、在线商品、发布异常，点击卡片跳转对应页面
- **刊登流程**：可视化展示「采集 → 校验 → 提交 → 在线」四步，点击任一步直接进入
- **最近任务**：最新采集与上架状态列表
- **系统状态**：后端、AI、数据库、采集器四项服务的健康度检测
- **快捷操作**：采集箱、上架记录、在线商品、店铺管理的快捷入口
- **系统公告**：后端发布的公告列表

### 5.2 商品采集（`/collect`）

采集箱是核心入口，所有待处理的货源商品集中在这里。两种采集方式：

1. **扩展采集（推荐）**：在货源站打开商品详情页，用扩展一键采集（见[第六节](#六浏览器扩展使用)）
2. **手动录入**：在采集箱内手动输入商品 URL 进行采集

采集完成后，商品以表格形式展示，可进行类目匹配、属性补全、SKU 设置、标题/描述优化、图片整理、定价等操作，为后续发布做准备。

### 5.3 上架记录（`/publish`）

查看和管理所有提交到 Ozon 的发布任务：

- 查看发布任务的状态（处理中 / 成功 / 失败）
- 批量操作
- 追踪失败原因，修正后重新提交

> 发布为异步任务，提交后系统后台每 60 秒自动刷新一次处理中任务的状态。

### 5.4 定价计算器（`/calculator`）

完整的利润测算工具，帮助你在刊登前算清利润空间：

- **基础信息**：售价、采购成本、类目佣金、重量、体积
- **物流信息**：跨境物流商、国内运费、代贴单费用
- **其他费用**：广告费占比、其他费用占比
- **利润分解**：实时显示毛利润、净利润、利润率

> 计算数据会暂存在浏览器本地（localStorage），刷新页面不丢失。

### 5.5 在线商品（`/online-products`）

管理已在 Ozon 上线的商品：

- 商品状态管理（在售 / 下架等）
- 批量操作
- 价格、库存、状态的监控与同步

### 5.6 AI 撰写（`/ai-write`）

基于 AI 的商品内容生成工具，支持四种模式：

| 模式 | 用途 |
|------|------|
| 标题优化 | 优化商品标题 |
| 描述生成 | 生成商品描述 |
| 关键词推荐 | 推荐搜索关键词 |
| 多语言翻译 | 翻译商品文案 |

操作步骤：

1. 选择模式（标题/描述/关键词/翻译）
2. 选择目标平台（Ozon / Wildberries / AliExpress）和目标语言（俄/英/德/中）
3. 输入原文或关键词
4. 点击「AI 生成」，结果展示在右侧
5. 可「复制」结果，或「应用到商品」

> AI 功能依赖模型配置，需先在「店铺管理 → 模型管理」中配置 API Key。

### 5.7 图片管理

**AI 图片生成（`/ai-image`）**：使用 AI 生成商品图片。

**我的图库（`/gallery`）**：管理已采集/上传的商品图片资产，支持收藏、筛选。

### 5.8 店铺管理

**绑定店铺（`/store-manage`）**：

- 店铺授权（绑定 Ozon 店铺）
- 币种管理（CNY 店铺 / RUB 店铺，影响定价汇率换算）
- 分组管理
- 批量操作

**模型管理（`/model-manage`）**：统一配置 AI 服务商，系统内所有 AI 功能共用此配置：

- DeepSeek
- 通义千问
- OpenAI
- 自定义（OpenAI 兼容接口）

配置项包括 API Key、Base URL、模型名等。

### 5.9 规划中功能

以下菜单已出现在导航中，但尚未实现，点击会提示「正在开发中」：

- 我的选品、关键词（选品分析）
- 跟卖下架（跟卖监控）
- AI 广告监控、自动移除促销（促销活动）
- 账户明细（店铺管理）

## 六、浏览器扩展使用

### 6.1 安装

见 [2.2 加载浏览器扩展](#22-加载浏览器扩展)。

### 6.2 扩展弹窗

点击浏览器工具栏的 GeekOzon 图标，弹出操作面板：

| 区域 | 功能 |
|------|------|
| **当前页面检测** | 自动识别当前标签页是否为可采集平台，显示「可采集 / 不支持」 |
| **采集当前商品** | 一键采集当前商品详情页到 ERP |
| **快速入口** | ERP 工作台、Ozon Seller、刷新状态 |
| **运行状态** | 检测 ERP 后端连通性、Seller 桥接可用性 |
| **店铺列表** | 展示已绑定店铺的授权状态与今日可刊登额度 |

### 6.3 悬浮栏

在支持的商品详情页，页面会自动注入采集悬浮栏，直接点击即可采集，无需打开弹窗。

### 6.4 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+C` | 采集当前商品 |
| `Ctrl+Shift+P` | 一键刊登 |

### 6.5 支持的采集平台

扩展在以下站点自动启用采集能力（需在对应域名下的商品详情页使用）：

- **Ozon**：ozon.ru / ozon.kz / ozon.by / ozon.com
- **1688**：1688.com
- **淘宝 / 天猫**：taobao.com / tmall.com
- **京东**：jd.com
- **拼多多**：pinduoduo.com / yangkeduo.com
- **速卖通**：aliexpress.ru / aliexpress.com
- **亚马逊**：amazon.com / .de / .co.uk / .fr / .it / .es / .ca / .co.jp / .ae
- **Wildberries**：wildberries.ru

### 6.6 Ozon Seller 桥接

扩展通过「跨标签页借权」机制调用 Ozon 卖家 API：

1. 在浏览器打开并登录 `https://seller.ozon.ru/`
2. 扩展会检测到该标签页，标记「桥接可用」
3. 之后发布商品、同步状态等操作会借助该标签页的登录态直接调用 Ozon API

> 若提示「未打开 seller.ozon.ru」，请先打开并登录卖家后台，再执行发布操作。

## 七、常见问题

**Q1：扩展弹窗显示「ERP 后端无法连接」？**
→ 确认后端服务已启动（`python app.py`），且访问地址为 `http://localhost:5000`。

**Q2：点击采集提示「当前页面不可采集」？**
→ 当前页面不在支持平台列表内，或未停留在商品详情页。请在支持站点的商品详情页重试。

**Q3：AI 生成失败？**
→ 检查「模型管理」中是否已配置对应服务商的 API Key，并确认网络可访问该服务商。

**Q4：发布任务一直停在「处理中」？**
→ 确认已打开并登录 `seller.ozon.ru`（Seller 桥接），或检查发布记录中的失败原因。

**Q5：图片无法被 Ozon 抓取？**
→ Ozon 只接受公网可访问的图片 URL。本地部署时需配置内网穿透、公网域名（`IMAGE_BASE_URL`）或七牛云对象存储，详见部署文档。

**Q6：采集的商品在哪里？**
→ 进入「采集箱」（`/collect`）查看，采集成功会出现在商品列表表格中。
